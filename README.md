This is a digital version of the game M.A.S.H. (Mansion, Apartment, House, Shack). You can edit the options in each category manually, or click "Shuffle Options) if you don't want to do all that work. You can choose any number for the magic count (which is basically like rolling a die but digital), or leave it blank and you'll get a random one. Click the "Predict My Future Button" when you're done to reveal your fate.

Enjoy!
